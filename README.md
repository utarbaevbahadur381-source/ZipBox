# ZipBox

Простой архиватор для Windows на Electron: открывает и распаковывает архивы, создаёт новые,
добавляет и удаляет файлы, ставит пароль, проверяет целостность. Есть перетаскивание файлов мышкой.

Форматы: открывает ZIP, 7Z, TAR, GZ, TGZ, BZ2, XZ. Создаёт ZIP, 7Z, TAR. (RAR не поддерживается.)

## Как получить ZipBox.exe

1. Установи Node.js (LTS) с https://nodejs.org
2. Запусти `build.bat` (двойной клик). Подожди несколько минут.
3. В папке `dist` появятся:
   - `ZipBox-1.0.0-x64.exe` — переносная версия, ставить не нужно
   - `ZipBox Setup 1.0.0.exe` — установщик (добавляет «Открыть с помощью» для архивов)

Чтобы просто запустить без сборки: `start.bat`.

## Если что-то не работает

- Ошибка про symbolic link при сборке: запусти `build.bat` от имени администратора
  или включи «Режим разработчика» в параметрах Windows.
- Не скачивается Electron (нет доступа к GitHub): перед сборкой выполни в командной строке
  `set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` и снова запусти `build.bat`.

## Горячие клавиши

Ctrl+O открыть · Ctrl+N создать · Ctrl+E распаковать · Del удалить из архива ·
Backspace на уровень вверх · Ctrl+A выделить всё · Enter / двойной клик открыть

## Сборка через GitHub (без установки Node.js)

1. Создай репозиторий на github.com (кнопка New) и загрузи в него все файлы этой папки,
   включая скрытую папку `.github`.
2. Открой вкладку Actions. Сборка стартует сама (или нажми Run workflow).
3. Через 3-5 минут открой завершённый запуск и скачай `ZipBox-windows` из раздела Artifacts.
4. Чтобы exe появился на странице Releases, создай тег: `git tag v1.0.0 && git push --tags`.
